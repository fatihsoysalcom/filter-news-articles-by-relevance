# Filter News Articles by Relevance

This example demonstrates a simplified approach to filtering a large volume of news articles based on keyword relevance. It simulates the process of reducing an overwhelming number of articles to a more manageable and relevant selection, similar to how AI-powered systems might distill information. The script generates mock articles and applies a scoring mechanism to identify highly pertinent content.

## Language

`python`

## How to Run

Save the code as `filter_news.py`.
Run from your terminal: `python filter_news.py`
